ENGLISH SKILLS GRADER V12.3 WEB

Deploy on Streamlit Community Cloud:
1. Upload these files to a GitHub repository.
2. In Streamlit Cloud, choose Deploy app.
3. Main file path: app.py
4. Add OpenAI API key in App settings > Secrets as:
OPENAI_API_KEY = "your-api-key"

This web version uses video upload for compatibility with HTTPS/cloud. Use original V12.3 for local live webcam recorder.
